# 🎬 AI Shorts & Video Generator | From User Comments

An ultra-fast AI video generation platform that creates short clips and full videos directly from user comments, prompts, or long video uploads.

## ✨ Key Features

1. **AI Shorts & Video Generation from User Comments**:
   - Turn any comment, prompt, question, or story into a viral Short or full Video in **3 to 8 seconds**.
   - **All Video Styles Supported**:
     - 🎬 **Live Action / Cinematic Realism** (35mm ARRI Alexa cinematography, photorealistic actors & lighting)
     - 🌸 **Anime / Japanese Manga** (Studio Ghibli, Makoto Shinkai & Ufotable cel-shaded visuals)
     - 🧸 **3D Animation** (Disney Pixar / stylized character render)
     - 🎥 **Cinematic 8K** (Hollywood movie lighting & anamorphic lenses)
     - ⚡ **Cyberpunk / Sci-Fi** (Neon glow, futuristic cities & synthwave)
     - 🌿 **Nature & Documentary** (National Geographic & BBC Earth wildlife realism)
     - 🏰 **Dark Fantasy & Mythical** (Glowing runes, magical ruins & ethereal art)
     - 📚 **Comic Book / Graphic Novel** (Bold ink outlines, halftone pop art)
     - ✨ **Smart Auto-Detect** (Intelligently detects style from the user's comment)
   - **Formats & Durations**:
     - Vertical **9:16** for YouTube Shorts, Instagram Reels, and TikTok
     - Landscape **16:9** for YouTube and widescreen displays
     - Flexible duration presets: 15s (Quick), 30s (Viral), and 60s (Extended)
   - **Neural Voiceover (TTS)**: Multiple lifelike voices (Christopher, Jenny, Guy, Aria, Ryan, Sonia) powered by Microsoft `edge-tts`.
   - **Viral Centered Captions**: TikTok / Shorts style bold yellow and neon subtitles.
   - **Ambient Audio Mixing**: Automatic on-the-fly ambient synth soundtrack ducked under narration.

2. **Video Clipper & Splitter**:
   - Split long uploaded videos into fixed-duration short clips with ultra-fast FFmpeg stream copy.

## 🚀 How to Run

1. Install dependencies:
```bash
pip install -r backend/requirements.txt
```

2. Start the server:
```bash
cd backend
python run.py
```

3. Open your browser:
Navigate to **http://localhost:8000/**
