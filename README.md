# 🎬 AI Clip Generator & Video Creator

An ultra-fast AI video generation platform that creates short videos directly from user comments, prompts, or long video uploads.

## ✨ Key Features

1. **AI Comment-to-Video Generation**:
   - Turn any comment, prompt, question, or story into a viral Short in **3 to 8 seconds**.
   - **Neural Voiceover (TTS)**: Multiple lifelike voices (Christopher, Jenny, Guy, Aria, Ryan, Sonia) powered by Microsoft `edge-tts`.
   - **AI Scene Visuals**: Multi-scene storyboard generation with online photorealistic generation and dynamic high-contrast procedural artwork.
   - **Viral Centered Captions**: TikTok / Shorts style bold yellow and neon subtitles.
   - **Ambient Audio Mixing**: Automatic on-the-fly ambient synth soundtrack ducked under narration.
   - **Aspect Ratios**: Vertical (9:16) for Shorts/Reels/TikTok and Horizontal (16:9) for YouTube.

2. **Video Clipper & Splitter**:
   - Split long uploaded videos into fixed-duration short clips with FFmpeg stream copy.

## 🚀 How to Run

1. Install dependencies:
```bash
pip install -r backend/requirements.txt
```

2. Start the server:
```bash
cd backend
python run.py
```

3. Open your browser:
Navigate to **http://localhost:8000/**
